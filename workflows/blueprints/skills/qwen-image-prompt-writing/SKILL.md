# Qwen 图像提示词撰写

## 工作流

1. 识别生图任务：是否需要渲染文字、是否参考图。
2. 参考 `references/qwen-image-guide.md` 中的模型卡与 API 规范。
3. 按「自然语言长描述 + 文字双引号 + positive_magic 质量后缀」组织 prompt。

## 核心写法规则

### 正向提示词（text）

- 必填，描述图像内容/风格/构图，支持中英文。
- qwen-image-2.0 系列最长 1300 tokens（其他系列约 800 tokens / 800 字符，超出自动截断）。
- 用自然语言写一段带空间布局、文字、人物的长句（改写器目标约 200 词，避免标签列表）。

### 需要渲染的文字

用双引号包起来：

```
"Qwen Coffee 😊 $2 per cup"
```

中文也一样：

```
"通义千问"
```

### ⚠️ CJK 触发陷阱（重要）

Qwen 改写器按 CJK 字符路由：**prompt 中只要出现一个汉字，整段会被中文改写器翻译为中文**。安全写法：主体用英文、需要保留原文的目标文字放引号内（引号内容受保护不被翻译）。中英混排时务必注意，否则英文描述会被整段译回中文。

### positive_magic 质量后缀（可选，社区习惯，非官方）

- 社区常用的稳定后缀，阿里云官方文档**无此规范**，且 Qwen 官方建议自然语言长句、避免标签列表，故仅为可选增补：
  - 英文：`, Ultra HD, 4K, cinematic composition.`
  - 中文：`, 超清,4K,电影级构图.`
- 注意：开启 `prompt_extend` 时改写器已自动补细节，此后缀冗余；且与自然语言写法略有张力，按需使用。

### negative_prompt（选填）

- 不需要时可以留空格 `" "`。
- 官方示例：`低分辨率,低画质,肢体畸形,手指畸形,画面过饱和,蜡像感,人脸无细节,过度光滑,画面具有AI感,构图混乱,文字模糊,扭曲`

### prompt_extend

- 是否开启提示词智能改写，默认 `true`。

### size

qwen-image-2.0 系列支持（分辨率需在 512×512 至 2048×2048 之间，默认 2048×2048）：

| size | 比例 |
|---|---|
| 2048 * 2048 | 1:1（默认） |
| 2688 * 1536 | 16:9 |
| 1536 * 2688 | 9:16 |
| 2368 * 1728 | 4:3 |
| 1728 * 2368 | 3:4 |

注：上述为 2.0 系列；qwen-image-max / qwen-image-plus 系列默认 1664×928 且可选比例不同，以官方文档为准。size 为独立 API 参数，不写进提示词正文。

## 输出规则

- 用自然语言组织长句描述，包含空间布局、主体、文字、风格、构图。
- 需要渲染的文字用双引号包裹并保持原文。
- 结尾追加对应语言的 positive_magic 质量后缀。
- 需要时提供 negative_prompt，不需要时留空格。
